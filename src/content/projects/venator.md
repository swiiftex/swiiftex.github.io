This was my first multiplayer game that went beyond silly prototypes with friends. It was a huge challenge I set myself to learn Unreal Engine and multiplayer networking in depth.

The game went through a few different temporary art styles, but the mechanics stayed the same. It was heavily playtested, and taught me a lot about multiplayer networking and combat design.

Ultimately, VENATOR was never released. The project lasted about two years of continued development, but it proved to be far too much at the time. I learned so much from it (and had a lot of fun playtesting!), so I still consider it a success. I'm still keen to make something for the slasher genre in the future.

Who knows — maybe VENATOR will return someday…
